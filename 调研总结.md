LLM 在毫米波无线传播 Prior Generation 中的调研汇报
====================================

* * *

一、调研目标
======

本阶段主要调研：
    LLM（以 GPT 为代表）是否能够用于毫米波无线传播 prior generation，
    以及其在 dense urban mmWave 场景中的能力边界。

重点关注：

* GPT 是否具备无线传播物理推理能力

* 是否能够稳定输出 structured prior

* 是否适合作为 RadioMapSeer pipeline 的一部分

* 哪些 propagation prior 可以可靠生成

* 哪些 quantitative 信息不适合由 GPT 生成

* * *

二、Benchmark 与能力分析
=================

本阶段主要测试了 GPT 在毫米波传播中的多个典型问题，包括：

* Reflection dominant NLoS propagation

* Human blockage

* Delay spread

* Angular spread

* Channel sparsity

* Beam tracking

* Beam misalignment

* Beamforming sensitivity

* LOS / NLoS propagation reasoning

重点场景：

* Dense Urban

* Urban Canyon

* Indoor mmWave

* Human / Vehicle blockage

* High mobility mmWave

* * *

三、主要调研结论
========

1. GPT 擅长的能力

------------

GPT 在以下方面表现较稳定：

| 能力                                | 表现  |
| --------------------------------- | --- |
| Reflection / Blockage 推理          | 较稳定 |
| Dense Urban propagation intuition | 较稳定 |
| LOS / NLoS reasoning              | 较稳定 |
| Channel sparsity understanding    | 较稳定 |
| Beam alignment intuition          | 较稳定 |
| Structured JSON prior generation  | 较稳定 |
| High-level propagation prior      | 较适合 |

GPT 特别适合：
    高层 propagation physics prior generation

例如：

* dominant_mechanism

* blockage_risk

* channel_sparsity

* beam_alignment_sensitivity

等字段。

* * *

2. GPT 不擅长的能力

-------------

GPT 在以下方面表现不稳定：

| 能力                        | 问题             |
| ------------------------- | -------------- |
| 精确 pathloss prediction    | 容易 hallucinate |
| 精确 delay spread 数值        | 不稳定            |
| 精确 attenuation estimation | 缺乏可靠性          |
| Dynamic channel evolution | 推理较弱           |
| 严格 stochastic modeling    | 不适合            |

因此：
    GPT 不适合作为精确无线信道模拟器。

* * *

四、Error Analysis
================

调研过程中发现的主要问题包括：

| 问题                    | 描述            |
| --------------------- | ------------- |
| Oversimplification    | 容易把传播规律绝对化    |
| Hallucinated values   | 容易生成不可靠精确数值   |
| Schema instability    | 初期 JSON 输出不稳定 |
| Environment ignorance | 部分场景忽略环境差异    |

后续通过：

* Physics rules injection

* Output constraints

* Prompt iteration

* Few-shot demonstrations

进行了改善。

六、最终稳定 Prior Schema
===================

目前较稳定、适合保留的 prior 字段包括：

| Field                      | Stability |
| -------------------------- | --------- |
| dominant_mechanism         | High      |
| blockage_risk              | High      |
| channel_sparsity           | High      |
| beam_alignment_sensitivity | High      |
| expected_delay_spread      | Moderate  |
| expected_angular_spread    | Moderate  |

不建议保留：

* exact_pathloss_dB

* exact_delay_ns

* exact_attenuation_dB

因为 GPT 在 quantitative prediction 上可靠性不足。

* * *

七、最终核心结论
========

目前调研结论为：
    LLM 更适合作为：
    高层 propagation prior generator，

    而不是：
    精确无线信道模拟器。

也就是说：

GPT 更适合：

* Reflection / blockage intuition

* Scene-level propagation reasoning

* Structured prior generation

而不适合：

* Precise EM simulation

* Exact quantitative channel modeling

* * *

八、LLM 在无线系统中的推荐位置
=================

目前认为：

LLM 最适合放在：
    High-level wireless prior generation layer

推荐 pipeline：
    Scene
    → LLM Prior
    → Generator
    → Radio Map

而不建议：
    LLM
    → Direct radio map generation
